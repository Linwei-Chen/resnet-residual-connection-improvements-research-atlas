# ResNet 残差连接改进研究地图

> 从恒等捷径到缩放、路由、聚合与可逆连接的证据导航

[在线阅读](https://linwei-chen.github.io/resnet-residual-connection-improvements-research-atlas/) · [综合报告](docs/REPORT.md) · [浏览结构化数据](https://github.com/Linwei-Chen/resnet-residual-connection-improvements-research-atlas/blob/main/atlas.json)

残差连接的演进并非一条从简单到复杂的单线竞赛。最稳定的共识是保持跨块近恒等传播并控制残差分支幅度；随机路径和输入自适应路由利用可跳过性换取正则化或计算效率；跨层聚合与可逆设计分别改变信息复用方式和存储/可逆性约束。地图按连接机制分流，再按证据从机制分析到跨任务系统验证分层，读者可同时比较收益、代价和没有被证明的部分。

## 路线导航

| 路线 | 主要关注点 |
|---|---|
| 恒等保真与投影 | 调整激活与归一化次序、通道/尺度变化方式或下采样捷径，使跨块信号尽量保持无阻传播。 |
| 残差更新控制与稳定化 | 通过固定或可学习缩放、方向投影、初始化、归一化替代与信号传播约束，控制残差分支注入恒等状态的幅度或方向。 |
| 随机路径正则 | 训练时随机丢弃、选择或扰动残差路径与多分支合并，以形成隐式子网络分布并抑制共适应。 |
| 自适应门控与路由 | 依据输入、空间位置、通道或残差响应，自适应决定传递、重标定、执行或跳过哪些更新。 |
| 跨层聚合拓扑 | 把单块二路相加扩展为多层级捷径、多项式路径、稠密连接、双路复用或层次聚合。 |
| 可逆与信息保持 | 用可逆耦合或 Lipschitz 约束重写残差映射，以重建激活、保存信息或支持可逆生成。 |
| 机制诊断与边界 | 用消融、谱分析、损失面、梯度或安全实验检验残差连接为何有效、何时失效以及常见解释的边界。 |

## 如何阅读

1. 打开[在线地图](https://linwei-chen.github.io/resnet-residual-connection-improvements-research-atlas/)，先从“路线 × 层级”总览判断领域结构。
2. 用关键词和出版状态缩小范围，再点击聚合节点比较同一分支中的工作。
3. 进入详情页，按“问题—机制—证据—局限—启示—来源”下钻到单项工作。
4. 需要完整论证时，继续阅读[综合报告](docs/REPORT.md)与[检索与证据审计](docs/SEARCH_AUDIT.md)；需要二次分析时使用 `data/` 导出。

页面不依赖服务端。克隆仓库后可直接双击 `index.html` 离线阅读；论文原文、代码和数据集等外部链接需要联网。

## 研究范围与证据边界

覆盖 2015 年前驱至 2026-08-13，可由正式论文、DOI、作者入口或官方代码核验、且直接改变 ResNet 捷径路径、残差分支与主路径合并、路径选择、跨块拓扑或为恒等传播服务的稳定化机制的工作。仅把 ResNet 当骨干的应用、只改卷积算子/宽度/深度而不改变连接行为的变体，以及 Transformer、U-Net、GNN 等专属 skip 技巧不进入主体。少量直接替代、机制诊断和负面证据作为桥接或背景保留；不声称穷尽任务特定长尾。

地图把出版状态、阅读优先级、证据质量和展示层级分别记录，避免把“已发表”“重要”“证据强”或“工程成熟”混为一谈。详情页中的机制图是依据文字证据绘制的解释性示意，不替代原论文图表或独立复核。

## 项目文件

- `index.html`：交互式研究全景、路线说明、时间线与完整索引。
- `paper.html?id=...`：每项工作的机制、证据、局限和一手来源详情。
- `atlas.json`：人工维护的结构化研究真源。
- `docs/REPORT.md`：领域综述、关键分歧、时间线与开放问题。
- `docs/SEARCH_AUDIT.md`：检索范围、纳排规则、覆盖限制和反证记录。
- `data/papers.json`、`data/papers.csv`、`data/references.bib`：便于阅读、分析与引用的导出。
- `planning/` 中公开的账本文件：范围合同、查询、筛选和核心主张的可追溯记录。

## 数据更新与复核

网页和数据导出由 [`build-research-atlas`](https://github.com/Linwei-Chen/build-research-atlas) 从 `atlas.json` 确定性生成。更新记录后，应重新编译并执行严格验证与真实浏览器回归；不要直接改写 `data/` 中的派生文件。

这是一份有明确截止日期和纳入边界的研究综述，不声称覆盖互联网上的全部长尾资料。若发现题名、状态、链接或证据表述需要修正，欢迎在仓库中提交问题并附一手来源。
